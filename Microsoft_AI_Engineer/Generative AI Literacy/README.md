# ChatGPT-Based Storytelling

This project demonstrates how generative AI can be used as a collaborative storytelling tool without requiring code or additional platforms. The goal was to guide ChatGPT through the creation of an original narrative by defining the setting, characters, tone, and direction of the story.

For the project, I worked with ChatGPT to develop a novella-style chapter and a shorter standalone scene. The writing process involved providing creative direction, reviewing the generated material, refining prompts, and revising details to improve consistency, characterization, pacing, and tone.

## Project Focus

- Developing characters, settings, and narrative themes through prompting
- Using iterative feedback to revise and expand AI-generated writing
- Maintaining continuity across longer narrative passages
- Exploring human-AI collaboration in a creative workflow

## Deliverables

The project files include the completed story chapter, the shorter scene, and supporting materials that document the storytelling exercise.

This is a generative AI literacy demonstration rather than a software development project; no programming or custom model training was required.
